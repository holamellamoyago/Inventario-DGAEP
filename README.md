## 🛠️ Tecnologías utilizadas

- **Framework:** Flutter (Dart)
- **Plataformas:** Android, iOS, Web
- **Backend:** Firebase (Firestore, Authentication)
- **Base de datos:** Firebase Firestore

---

## 📱 Características

- ✅ Control de inventario completo
- ✅ Escaneo de códigos de barras
- ✅ Gestión de usuarios y roles
- ✅ Sincronización en tiempo real
- ✅ Reportes y estadísticas
- ✅ Interfaz adaptativa (móvil y escritorio)

---

## 🚀 Instalación

```bash
git clone https://github.com/holamellamoyago/Inventario-DGAEP.git
cd Inventario-DGAEP
flutter pub get
flutter run
```

> **Nota:** Necesitas configurar tu propio proyecto de Firebase y añadir los archivos `google-services.json` (Android) y `GoogleService-Info.plist` (iOS).
